# Changelog

## 0.1.2 (2026-11-09)

- Readme wording: the sparkle changes are described as defaults, since each is a setting.
- Corrects the 0.1.1 entry below, which said Drift keeps sparkles from rising higher than the game's. That is only true at its default of 0.5; higher values let them rise higher.
- No gameplay changes.

## 0.1.1 (2026-11-09)

- Gentler defaults: twice as many sparkles lasting twice as long, 1.5 times as big, 1.5 times as bright and spread 1.5 times as wide.
- New `Drift` setting: how fast sparkles drift away from the item, as a multiple of the game's speed. The default, 0.5, keeps the longer-lasting sparkles from rising higher than the game's; raise it to let them go higher.
- An existing config file keeps its values. Delete it to get the new defaults.
- The description says the mod makes dropped items easier to spot, which is all it does.

## 0.1.0 (2026-11-06)

- First release: makes the sparkles on items lying on the ground easier to spot. By default three times as many, three times as big, lasting three times as long, twice as bright and spread twice as wide.
- Changes to the settings apply as soon as the file is saved, even mid-game.
