# Changelog

## 0.1.1 (2026-11-09)

- Readme wording: the +1, +2 and fast reverse speeds are described as defaults, since each is a setting. No gameplay changes.

## 0.1.0 (2026-11-06)

- First release.
- Press forward at Full sail for +1 (2x sail force) and +2 (3x).
- Press back at reverse for fast reverse (2x rowing force).
- Forward and reverse rowing speed are configurable and default to the game's.
- A label beside the ship's speed indicator shows the extra level.
