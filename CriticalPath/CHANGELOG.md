# Changelog

## 0.1.5 (2026-11-09)

- Description and readme wording: they no longer promise it never suggests anything you don't need, or the most survivability for the least time. The armor target is described as a level the mod sets for each boss. No gameplay changes.

## 0.1.4 (2026-11-09)

- The panel steps aside while you split a stack.
- With a chest open, the panel stays on screen.
- When the next boss calls for a resistance you don't have, the panel says so and won't call you ready. For Moder that's frost resistance, which also keeps out the Mountains' cold.

## 0.1.3 (2026-11-06)

- Description fix: CriticalPath reminds you to find the boss's altar and says which kind of Vegvisir to look for. It never marks the altar or reveals where it is.

## 0.1.2 (2026-11-06)

- New description and an up-to-date README. No gameplay changes.

## 0.1.1 (2026-11-03)

- Keeps food, harvest and comfort suggestions once you're ready for the next boss, instead of showing only the boss line.
- Suggests finding the boss's altar (via its Vegvisir) last, once everything else is ready.
- The panel sits below QuickStackStore's button.

## 0.1.0 (2026-11-03)

- First release: suggests the next step towards better tools, food and just enough armor for the next boss.
